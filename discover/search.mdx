Search accepts plain-language queries and returns opportunities from SAM.gov, Grants.gov, DIBBS, and over 1,000 state and local sources. It matches on meaning, not just keywords.

```
Find IT modernization contracts with the Navy over $5M
```

## Opportunity types

The Search flyout in the sidebar covers five opportunity sources, each with its own search page:

| Type | What it covers |
| --- | --- |
| **Federal Contracts** | Contract opportunities from SAM.gov: solicitations, presolicitations, sources sought, and special notices |
| **Federal Grants** | Grant opportunities from Grants.gov |
| **DIBBS Contracts** | DLA DIBBS solicitations, searchable by NSN and part number |
| **SBIR / STTRs** | Small Business Innovation Research and Technology Transfer topics |
| **State & Local Contracts** | SLED opportunities aggregated from 1,000+ state and local procurement portals |

<Tip>
Set your default opportunity type under **Settings → Preferences** so the Search icon always lands where you work most.
</Tip>

## Searching effectively

* **Write descriptive queries.** "Cloud migration services for civilian agencies" returns better results than a list of disconnected keywords.
* **Use filters for structured criteria.** NAICS and PSC codes, set-asides, buyers, due dates, and solicitation numbers all live in the filter panel. For a pure code or number lookup, set the filter and leave the query blank.
* **Check the amendment history.** When a solicitation is amended, Sweetspot highlights the differences between versions so you can see exactly what changed.

See the [Prompting Guide](/prompting-guide) for more search tips.

## From result to pursuit

From any opportunity you can:

* **Open the full details**: response deadline, set-aside, notice type, AI summary, solicitation details and documents, point of contact, project timeline, and linked awards showing the current recipient.
* **Ask AI** about it: requirements, evaluation criteria, incumbent history, and fit, with cited answers. See [Ask AI](/ai/ask-ai).
* **Generate a capture brief** for a structured bid/no-bid analysis with win probability and gap assessment.
* **Bookmark it** to a shared watch list. See [Bookmarks](/discover/bookmarks).
* **Add it as a pursuit** to start working it in your pipeline. See [Pursuits](/pursuits/dashboard).
